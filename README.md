# MFPI Tracker

Минималистичный трекер системы MFPI:

- Main — главное направление
- Finance — доходное направление
- Perspective — перспективное направление
- Involvement — вовлекающее направление
- ежедневные шаги
- показатель покрытия дня
- серия полных дней
- ограниченные по времени эксперименты
- экспорт и импорт данных
